# Yllka — Product Designer portfolio

Next.js (App Router) + Tailwind CSS v4. Static content site — no database,
no backend.

## Getting started

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Adding your real project screenshots and copy

See **[CONTENT-GUIDE.md](./CONTENT-GUIDE.md)** — every project, image, and
piece of copy lives in `src/content/*.ts`, and screenshots drop into
`public/images/...` with no code changes required.

## Deploying

```bash
npm run build
npm run start   # or deploy the .next output to Vercel / any Node host
```
